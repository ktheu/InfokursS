\question[5]
Schreibe eine Funktion \texttt{binaereSuche(a, x)}, die in der sortierten Liste \texttt{a} den Wert \texttt{x} sucht. Sie gibt den Index von \texttt{x} zurück, oder -1, wenn \texttt{x} nicht vorkommt.
\begin{solutionbox}{5cm}
\begin{lstlisting}
def binaereSuche(a, x):
    L = 0
    R = len(a) - 1
    while L <= R:
        mid = L + (R - L) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            L = mid + 1
        else:
            R = mid - 1
    return -1
\end{lstlisting}
\end{solutionbox}
