\question[3]
Was bedeuten die folgenden Angaben in einer Dokumentation?
\begin{parts}
\part \texttt{round(number, ndigits=None)}: Was bedeutet \texttt{ndigits=None}?
\part \texttt{Raises ValueError if the value is not present.}
\part \texttt{randint(a, b): Return random integer in range [a, b], including both end points.}
\end{parts}
\begin{solutionbox}{2.5cm}
a) Das Argument \texttt{ndigits} ist optional, ohne Angabe gilt der Standardwert \texttt{None}. \\
b) Ist der Wert nicht vorhanden, gibt es einen \texttt{ValueError}. \\
c) Die Funktion gibt eine zufällige ganze Zahl von a bis b zurück, a und b sind möglich.
\end{solutionbox}
