\question[2]
In x sei eine ganze Zahl gespeichert. Schreibe einen Python-Ausdruck, der genau
dann wahr ist, wenn x zwischen 110 und 120 (einschließlich) liegt oder durch 7 teilbar ist.
\begin{solutionbox}{2cm}
\begin{lstlisting}
(110 <= x and x <= 120) or x % 7 == 0
\end{lstlisting}
\end{solutionbox}
