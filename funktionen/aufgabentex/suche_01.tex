\question[3]
Schreibe eine Funktion, die sich so verhält, wie im folgenden docstring beschrieben.
Die Funktion soll mit \texttt{return} verlassen werden, sobald das Ergebnis feststeht.
\begin{lstlisting}
'''
a: Liste mit Zahlen
returns: True, wenn die Liste aufsteigend sortiert ist, sonst False

>>> ist_sortiert([1, 3, 3, 7])
True
>>> ist_sortiert([1, 5, 2, 7])
False
>>> ist_sortiert([])
True
'''
\end{lstlisting}

\begin{solutionbox}{4cm}
\begin{lstlisting}
def ist_sortiert(a):
    for i in range(len(a) - 1):
        if a[i] > a[i + 1]:
            return False        # erstes Paar in falscher Reihenfolge
    return True
\end{lstlisting}
\end{solutionbox}
