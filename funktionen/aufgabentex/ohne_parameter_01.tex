
\question[1]
Schreibe eine Funktion, die sich so verhält, wie im folgenden docstring beschrieben.
 
\begin{lstlisting}
'''
returns: string, die Zeichenfolge 'x.'

>>> func2()
'x.'
'''

\end{lstlisting}

\begin{solutionbox}{3cm}
\begin{lstlisting}
def func2():
    return 'x.'
\end{lstlisting}
\end{solutionbox}
