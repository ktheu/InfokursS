\question[4]
Das folgende Programm läuft, verstößt aber mehrfach gegen PEP 8. Schreibe es nach den Regeln von PEP 8 neu.
\begin{lstlisting}
def QuadratSumme( a,b ) :
  S=a*a+b*b
  return S
print(QuadratSumme(3,4))
\end{lstlisting}
\begin{solutionbox}{3.75cm}
\begin{lstlisting}
def quadrat_summe(a, b):
    s = a * a + b * b
    return s


print(quadrat_summe(3, 4))
\end{lstlisting}
\end{solutionbox}
