\question[3]
Beschreibe, was eine Entwicklungsumgebung (IDE) ist und nenne zwei Funktionen einer IDE,
 die beim Programmieren unterstützen.

\begin{solutionbox}{5cm}
Eine Entwicklungsumgebung (IDE) ist ein
Programm, das beim Erstellen von Software
unterstützt.

Beispiele für Funktionen: \\
- Schreiben, Bearbeiten und Verwalten von Code  \\
- Ausführen von Programmen \\
- Fehlersuche mit einem Debugger \\
- Zugriff auf eine Konsole zur Ein- und Ausgabe
\end{solutionbox}
