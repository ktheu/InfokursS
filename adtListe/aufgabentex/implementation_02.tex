\question[4]
Das Bild zeigt das UML-Diagramm unseres Datentyps Liste. Implementiere in Python die Klassen Eintrag und die Klasse Liste 
(nur Konstruktor und die Methoden endpos und advance). Achte dabei auf mögliche Fehlersituationen.

\includegraphics[height=3.5cm]{\pfad/liste_uml.png}


\begin{solutionbox}{7.5cm}
\begin{lstlisting}
class Eintrag:
    def __init__(self):
        self.inhalt = None
        self.next = None

class Liste:
    def __init__(self):
        self.anf = Eintrag()
        self.pos = self.anf
           
    def endpos(self):
        return self.pos.next is None

    def advance(self):
        if self.endpos(): raise RuntimeError("Fehler: Liste am Ende")
        self.pos = self.pos.next
\end{lstlisting}
\end{solutionbox}
