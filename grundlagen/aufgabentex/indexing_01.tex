\question[2]
Gegeben ist der String s = 'Obstkiste'. \\
Weise der Variablen c1 mit einem positiven Index das Zeichen 'i' in dem String s zu. \\
Weise der Variablen c2 mit einem negativen Index das Zeichen 'i' in dem String s zu. 
\begin{solutionbox}{3cm}
\begin{lstlisting}
s = 'Obstkiste'
c1 = s[5]
c2 = s[-4]
\end{lstlisting}
\end{solutionbox}
