\question[2]
Schreibe ein Python-Programm, das die folgenden Anweisungen ausführt:
\begin{lstlisting}[language={}]
Setze a auf 1, b auf a plus 2, c auf 1 minus b.
Gib a, b und c in einer Zeile aus.
\end{lstlisting}

Was erscheint auf der Konsole, wenn das Programm ausgeführt wird?
\begin{solutionbox}{4cm}
\begin{lstlisting}
a = 1
b = a + 2
c = 1 - b
print(a, b, c)
\end{lstlisting}
Ausgabe auf der Konsole:
\begin{lstlisting}
1 3 -2
\end{lstlisting}
\end{solutionbox}
