\question[3]
Schreibe ein Python-Programm, das die folgenden Anweisungen ausführt:

Erstelle drei Variablen a, b, c mit den Inhalten \texttt{'Heute'}, \texttt{'ist'}, \texttt{'Montag'}.
Erstelle dann durch Aneinanderpappen mit a, b, c eine Variable satz
mit dem Inhalt \texttt{'Heute ist Montag.'} (Punkt nicht vergessen!)

\begin{solutionbox}{3cm}
\begin{lstlisting}
a = 'Heute'
b = 'ist'
c = 'Montag'
satz = a + ' ' + b + ' ' + c + '.'
\end{lstlisting}
\end{solutionbox}
