Die Mitglieder können an mehreren Kursen teilnehmen.

\begin{itemize}
\item Jedes Mitglied besitzt eine Mitgliedsnummer und einen Namen.
\item Jeder Kurs besitzt eine Kursnummer und eine Bezeichnung.

\end{itemize}
