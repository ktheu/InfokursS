\question[4]
Eine Fahrschule verwaltet Informationen über Schüler und Fahrlehrer.

\begin{itemize}
\item Jeder Schüler besitzt eine Schülernummer, einen Namen und ein Geburtsdatum.
\item Jeder Fahrlehrer besitzt eine Personalnummer und einen Namen.
\item Ein Fahrlehrer unterrichtet mehrere Schüler.
\item Jeder Schüler wird genau einem Fahrlehrer zugeordnet.
\end{itemize}

Bestimme die Entitätstypen und ihre Attribute.
Beschreibe die Beziehung zwischen Schüler und Fahrlehrer und gib die Kardinalität an.

\begin{solutionbox}{6cm}
\textbf{Entitätstypen:}
\begin{itemize}
\item Schüler - Attribute: Schülernummer, Name, Geburtsdatum
\item Fahrlehrer - Attribute: Personalnummer, Name
\end{itemize}

\textbf{Beziehung:}

Ein Fahrlehrer unterrichtet Schüler.

\textbf{Kardinalität:}

1:n-Beziehung

Ein Fahrlehrer kann mehrere Schüler unterrichten, jeder Schüler hat jedoch genau einen Fahrlehrer.
\end{solutionbox}
