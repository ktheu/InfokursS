\question[4]
Gegeben ist die Liste \texttt{a = [3, 27, 14, 8, 41, 19]}. Schreibe ein Python-Programm, 
das mit linearer Suche das Element findet, das am nächsten an der Zahl 20 liegt 
(kleinster Wert von \texttt{abs(x - 20)}), und dieses ausgibt.

\begin{solutionbox}{4cm}
\begin{lstlisting}
a = [3, 27, 14, 8, 41, 19]
best = a[0]
best_abstand = abs(a[0] - 20)
for x in a:
    if abs(x - 20) < best_abstand:
        best_abstand = abs(x - 20)
        best = x
print(best)
\end{lstlisting}
\end{solutionbox}
