\question[3]
Schreibe eine Python-Funktion \texttt{ist\_gerade(zahl)}, die einen Wahrheitswert zurückgibt,
je nachdem ob \texttt{zahl} gerade ist. Teste die Funktion mit zwei verschiedenen Zahlen.

\begin{solutionbox}{4cm}
\begin{lstlisting}
def ist_gerade(zahl):
    return zahl % 2 == 0

print(ist_gerade(4))
print(ist_gerade(7))
\end{lstlisting}
\end{solutionbox}
