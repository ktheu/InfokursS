\question[3]
Schreibe ein Python-Programm, das eine Zeichenkette \texttt{"42"} in eine Ganzzahl umwandelt,
diese um 8 erhöht und das Ergebnis als Zeichenkette wieder ausgibt (Typumwandlung).

\begin{solutionbox}{4cm}
\begin{lstlisting}
text = "42"
zahl = int(text)
zahl = zahl + 8
ergebnis = str(zahl)

print(ergebnis)
\end{lstlisting}
\end{solutionbox}
