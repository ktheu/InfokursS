\question[2]
Gegeben sind folgende Variablenzuweisungen in Python:
\begin{lstlisting}
a = 7
b = 3.5
c = "Hallo"
d = True
\end{lstlisting}
Gib für jede Variable den passenden Datentyp an.

\begin{solutionbox}{3cm}
\begin{lstlisting}
a: Ganzzahl (int)
b: Gleitkommazahl (float)
c: Zeichenkette (str)
d: Wahrheitswert (bool)
\end{lstlisting}
\end{solutionbox}
