\question[2]
In welcher Komplexitätsklasse ist die Laufzeit der
   Funktion \texttt{foo} in Abhängigkeit von der Länge
    n der übergebenen Liste a im best case und im worst case?
\begin{lstlisting}
def foo(a):
    n = len(a)
    for i in range(n):
        if a[i] == 7:
            for j in range(n):
                for k in range(n):
                    print("hello")
\end{lstlisting}

\begin{solutionbox}{1cm}
best case: $O(n)$, worst case: $O(n^3)$
\end{solutionbox}
