\question[3]
Gib für jede Zählschleife den passenden Schleifenkopf in Python an.
\begin{parts}
\part \texttt{für i von 1 bis 10:}
\part \texttt{für i von 0 bis n-1:}
\part \texttt{für i von n bis 1 abwärts:}
\end{parts}
\begin{solutionbox}{2.5cm}
\begin{lstlisting}
for i in range(1, 11):
for i in range(n):
for i in range(n, 0, -1):
\end{lstlisting}
\end{solutionbox}
