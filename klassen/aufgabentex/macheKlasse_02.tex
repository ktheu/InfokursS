\question[3]
Schreibe Code, der den folgenden Dialog möglich macht:

\begin{lstlisting}
k1 = K(1)
k2 = K(2)
print(k1.x, k1.y, k2.x, k2.y)

1 1 2 2
\end{lstlisting}
\begin{solutionbox}{3cm}
\begin{lstlisting}
class K:
    def __init__(self, x):
        self.x = x
        self.y = x
\end{lstlisting}
\end{solutionbox}
